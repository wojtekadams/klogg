## Privacy

Your data is none of our business. klogg does not send out the contents of your files, your keyboard input,
screen contents, file names, host names, user names or passwords.

**Update checking.** By default klogg checks about once a week whether a newer version is available by
downloading a small file (`latest.json`) from this project's GitHub repository. The request contains no data
about you. You can turn update checking off in the app's preferences. We do not store any metadata about
these requests; GitHub's own [privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) applies to the download.

**Crash reports.** This fork does not include crash reporting and does not send crash data anywhere.

This website is hosted on GitHub Pages and does not use cookies, analytics or tracking.
